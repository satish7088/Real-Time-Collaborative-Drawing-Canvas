# Time accounting

This project was implemented and reviewed with AI assistance. The session was interrupted by an account usage-limit block; total wall-clock elapsed time would misrepresent active work.

| Measured segment | UTC interval | Elapsed |
| --- | --- | --- |
| Final rendering review, checkpoint/worker modifications and retesting | 2026-09-10 17:52:36 → 17:59:13 | 6 minutes 37 seconds |
| Final automated browser run (included in that work window) | 2026-09-10T17:58:43.834Z → 2026-09-10T17:59:13.212Z | 29.4 seconds |

The first segment is bounded by recorded tool timestamps. It is **not the total project time**, and the browser duration must not be added again. Earlier design/implementation and later documentation/packaging were not separately timed. No human developer-hour figure is invented. If the assignment requires your personal hours, add your actual time reviewing, testing and modifying the submission separately.
